# Aspie Planner
Developer for and designed in collaboration with my autistic girlfriend, Aspie Planner is a light-weight calendar/organizer to help keep track of recurring every-day tasks.

Core feature is the ability to schedule tasks to recur either on specific weekdays, or in static (eg. repeats every 5 days) or flexible intervals (repeat every 15-20 days), and provides a simple overview of due tasks.

At present, UI is in Danish. English localization due if interest is expressed.
